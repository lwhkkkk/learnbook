# 个人技术课程图文电子书库 (LearnBook)

本项目归档由高质量公开课、视频教程及官方原版资料重构而成的中英文双语图文电子书。

每个课程讲次均包含：
- 完整重构的教科书级 Markdown 讲义（含严谨数学公式推导与 Mermaid 流程图）
- 支持本地独立启动的交互式 HTML 电子书（带 KaTeX 数学渲染、图表与视频帧放大灯箱）
- 官方课件（Slides）与讲义（Notes）PDF 归档
- 精校行级字幕对照稿
